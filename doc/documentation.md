# GitHub Workflow Documentation

## Steps
1. Create an Issue to describe new work.
2. Create a branch for your changes.
3. Make edits and commit them.
4. Push the branch and open a Pull Request.
5. Link the PR to the Issue (use "Closes #issue-number").
6. Reviewer approves and merges the PR.
7. Issue closes automatically and progress updates in the project board.

## Notes
- Always follow the [Contributing Guide](https://github.com/Elnsor/learn-github/blob/main/CONTRIBUTING).
- Use the project board to track status and reviewer assignment.
