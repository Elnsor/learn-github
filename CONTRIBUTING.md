# Contributing Guide

Thank you for considering contributing to this project!  
Please follow these steps to make your contribution smooth and effective.

## 🛠 How to Contribute
1. Fork the repository.
2. Create a new branch for your changes:
   ```bash
   git checkout -b feature-name
   ```
3. Make your changes and commit them with clear messages.
4. Push your branch and open a Pull Request (PR).

## 📋 Issues
- Before starting work, check if an issue already exists.
- If not, open a new issue describing the problem or feature request.
- Link your PR to the issue using `Closes #issue-number`.

## ✅ Code Style
- Keep commits small and focused.
- Use descriptive commit messages.
- Follow the project’s coding conventions.

## 💬 Communication
- Be respectful and constructive in discussions.
- Use the project board to track progress.
